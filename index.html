Sobre os indicadores

A planilha contém a programação, mas não registra presença nem cancelamentos. As aulas com data anterior a hoje são consideradas concluídas apenas para estimar o progresso; isso não confirma que a aula ocorreu. Os encontros de hoje permanecem por vir.

Os outros links não permitiram exportação pública (autenticação ou link indisponível). Selecione o curso, exporte as abas Calendário e VISOR como CSV no Google Planilhas e importe cada arquivo nos botões acima. Os dados importados ficam neste navegador.
